How to publish a change

  1. Edit anything on this page — events, quotes, booking links.
  2. Click Copy JSON at the top right.
  3. Click Open site.json on GitHub below, then the pencil icon.
  4. Select all the existing text, paste over it, and click Commit changes.
  5. Done — the live site updates itself in about 30 seconds.
